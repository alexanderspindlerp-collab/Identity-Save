Database setup and recovery:

- Run the txAdmin recipe only against a brand-new, empty database.
- The recipe imports ESX `legacy.sql`, which creates tables and then adds indexes and seed data. It is not a repeatable migration.
- If the recipe stops with `Table 'addon_account' already exists`, use a different new empty database for the next install. A failed run may have already created some tables. Do not rerun the recipe against that partially initialized database, and do not drop tables from a database containing data you need.
