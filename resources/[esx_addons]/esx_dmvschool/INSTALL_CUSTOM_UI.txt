INSTALLATION

1. Backup din gamle esx_dmvschool mappe.
2. Upload denne esx_dmvschool mappe til resources.
3. Sørg for at server.cfg har: ensure esx_dmvschool
4. Kør: refresh og restart esx_dmvschool
