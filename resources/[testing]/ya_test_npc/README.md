# ya_test_npc

Midlertidig test-resource til udvikling på localhost.

## Kommandoer

- `/testnpc` — spawner en test-NPC foran dig
- `/testnpc s_m_y_dealer_01` — spawn med anden ped-model
- `/delselvnpc` — fjerner test-NPC

## Brug

1. Tilføj `ensure ya_test_npc` i server.cfg (under `[test]` mappen)
2. Brug **ox_target** (øje) på NPC'en
3. Slet hele mappen når I launcher på VPS

**OBS:** Denne resource er kun til test — ikke til produktion.
