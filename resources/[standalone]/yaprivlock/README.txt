YAPRIVLOCK RESET V10

Denne version er lavet for at få tingene til at virke igen:
- Ingen NetworkGetEntityIsNetworked
- Ingen dør/bagagerums bones
- Lås / Lås op vises kun for ejeren
- Åbn bagagerum vises fast
- Hvis bilen er låst, kan bagagerum ikke åbnes
- Politiet kan bryde bilen op

INSTALL:
1. Stop serveren.
2. Slet din gamle yaprivlock mappe.
3. Upload denne yaprivlock mappe.
4. Start rækkefølge:

ensure oxmysql
ensure es_extended
ensure ox_lib
ensure ox_target
ensure ox_inventory
ensure yaprivlock

5. Restart serveren helt.
