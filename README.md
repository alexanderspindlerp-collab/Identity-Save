Identity ESX Legacy template

This complete template is split into six ZIP downloads. Download all six and extract each into the same Identity-Save repository folder. Part 01 contains recipe.yaml, server.cfg, config/, documentation and part of resources/. Parts 02-06 contain the remaining resources/. Let the resources folders merge.

Do not upload the ZIP files themselves. Upload the extracted files using GitHub Desktop. txAdmin must be able to download the repository; private GitHub repositories may not work with download_github.

Use a new empty database. The recipe imports standard ESX SQL. Custom SQL is listed in SQL-IMPORT-NOTES.txt and is not auto-imported. Only publish scripts you have permission to share. web_admin_bridge, uz_AutoShot, r-coords and ya_test_npc are not started.
